# Internationalization

Mission Control supports English (`en`) and Italian (`it`) through the shared `I18nProvider`.

## Implementation

- Message catalogs: `src/locales/en.json` and `src/locales/it.json`
- Provider and language switcher: `src/lib/i18n.tsx` and `src/components/LanguageSwitcher.tsx`
- Locale resolution and fallback: `src/lib/i18n-core.ts`
- Locale-aware formatting: `src/lib/format.ts`

The selected locale is persisted in `localStorage`. Missing keys fall back to English; a key missing from both catalogs remains visible as its key name instead of silently disappearing.

All user-facing dashboard, Kanban, Chat, canvas, dialog, tooltip, placeholder, and accessibility copy is resolved through the active catalog. Runtime values such as IDs, model names, paths, slugs, file formats, numbers, and user-generated content are intentionally preserved.
